# ToDo Module – Overview

## Purpose

El módulo ToDo permite transformar ideas definidas en trabajo ejecutable.

Mientras que el módulo Brainstorm está diseñado para capturar ideas sin estructura ni presión, el módulo ToDo se enfoca en organizar esas ideas en proyectos concretos que puedan ejecutarse progresivamente.

Su objetivo es facilitar la planificación personal sin generar sobrecarga cognitiva, permitiendo dividir objetivos grandes en unidades de trabajo pequeñas y manejables.

---

## What is an Idea?

Dentro del contexto del módulo ToDo, una idea representa una intención clara de realizar algo.

Una idea puede convertirse en un proyecto cuando el usuario decide estructurarla en objetivos y tareas ejecutables.

Ejemplos de ideas que pueden convertirse en proyectos:

- Reformar el setup de escritorio
- Mejorar el interior del auto
- Construir una nueva funcionalidad en una aplicación
- Organizar un espacio de trabajo

El módulo ToDo no se encarga de capturar ideas iniciales. Ese rol pertenece al módulo Brainstorm.

---

## Core Principles

El diseño del módulo se basa en los siguientes principios:

**1. Reducción de carga cognitiva**  
El sistema evita mostrar demasiadas tareas simultáneamente para prevenir bloqueo o evitación.

**2. Ejecución progresiva**  
Los proyectos se descomponen en objetivos y tareas pequeñas que pueden completarse paso a paso.

**3. Planificación flexible**  
Las estimaciones y fechas pueden ajustarse sin penalizaciones.

**4. Separación entre planificación y ejecución**  
El sistema distingue entre una vista global de planificación y una vista enfocada en la ejecución diaria.

---

## Scope

El módulo ToDo gestiona:

- Proyectos
- Objetivos
- Tareas
- Estimaciones de tiempo
- Fechas estimadas y reales
- Estados de progreso

Este módulo es responsable de la estructura y seguimiento del trabajo ejecutable del usuario.

---

## Relationship with Other Modules

El módulo ToDo trabaja en conjunto con otros módulos del sistema.

**Brainstorm Module**

Brainstorm es el espacio donde se capturan ideas sin estructura.  
Cuando una idea está lo suficientemente clara, puede convertirse en un proyecto dentro del módulo ToDo.

Flujo esperado:

Brainstorm → ToDo

Esto permite separar el proceso creativo del proceso de ejecución.

---

## User Context

El módulo está diseñado para uso personal.

Su enfoque principal es ayudar al usuario a organizar proyectos de su vida cotidiana, tales como:

- proyectos personales
- mejoras del hogar
- aprendizaje
- desarrollo de software
- mantenimiento de objetos o espacios

El sistema prioriza claridad, simplicidad y sostenibilidad en el uso diario.

---

## Non-Goals

El módulo ToDo no busca reemplazar herramientas complejas de gestión de proyectos empresariales.

Quedan fuera del alcance del módulo:

- gestión de equipos
- colaboración multiusuario
- planificación rígida tipo Gantt empresarial
- métricas de productividad agresivas
- automatización compleja de flujos de trabajo

El sistema está pensado para acompañar el trabajo personal de manera flexible y sostenible.
